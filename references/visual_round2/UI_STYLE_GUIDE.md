# 第二轮 UI 规范
Detailed Retro Pixel Art + Early Internet Desktop UI。前三原图定义场景、第四原图定义窗口组合机制、四概念图仅辅助布局。
壁纸/住所640×360、缩略图320×180、图标32×32、头像32×32、人物32×64、控制16×16。纹理最近邻；基准1280×720的2倍场景显示。正文16px、元信息14px、窗口标题17px，系统回退字体确保中文可读。不引入第三方字体。
环境蓝灰#233047/#3d5267、前景炭灰#1a2130；局部暖灯#d9a16a，室内木色#755746；内容底灰白#dddcd4，文字#28364a。标题栏激活蓝灰、未激活炭灰，细高光/暗边和偏移阴影；按钮为直角轻边框，不用厚圆角/霓虹/后台大卡片。
桌面图标左列，个人小组件右侧，任务栏底部44px。动态880×550、消息720×510、视频820×510，详情560×440；窗口所有定位与拖动限制在任务栏上方。内容滚动与固定输入区分离。
壁纸必须有消失点、不同形态建筑、路面反光、电线与近景物件；不使用重复矩形高楼阵列。帖子避免等高等配图模板；消息采用独立双栏布局与头像时间、轻量气泡；视频使用封面模拟播放，明确标注静态演示。
