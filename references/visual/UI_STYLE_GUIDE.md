# UI 执行规范
Detailed Retro Pixel Art + Early Internet Desktop UI。
场景与软件分工：场景通过像素光照表达冷雨与暖室；软件通过独立窗口、标题栏和内容排版表达个人电脑感，不能把场景画法机械变成纯色方块。
有限色板：#1b2333、#293b52、#394a60、#566a7d、#b8c3c6、#e1ded4、#cb9565。正文浅灰底深色字；标题栏蓝灰，暖色只作状态点。
壁纸 640×360，1280×720 最近邻 2 倍显示；图标24×24，头像32×32，缩略图160×88，控件16×16。UI坐标使用1280×720逻辑画布；1920×1080检查排版，非整数显示不作为正式像素发行比例。
动态880×530，消息660×470，内容布局不同，可叠放。标题栏32高，边框2，正文16，行间距6；标题与数字可有像素感，不引入未经审核字体。
禁止厚圆角、塑料渐变、密集霓虹、企业后台卡片及默认控件堆砌。参考图不作壁纸、不裁切为资产；全部新PNG由可复现本地绘图脚本原创绘制。
