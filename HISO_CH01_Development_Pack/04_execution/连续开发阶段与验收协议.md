# 连续开发阶段、任务优先级与验收协议

## 总体策略

**一次交给 Codex，自行推进 Phase 0–6 至完整可玩再集中验收。** 每阶段以实测通过为内部关卡，不要求用户看一小段就反馈；若失败应自行修复或记为可降级缺陷继续推进。P0 阻断则优先修复，不用在某个 UI 特效上磨掉全部时间。

## Phase 0：审查与保护（约占工作量 5%）

- 检查现有场景、输入、UI、订单、电脑、存档、资源、Git 工作树；记录与旧开发文档兼容性。
- 输出 `docs/CH01_IMPLEMENTATION_STATUS.md` 与功能差距矩阵。
- 对用户未提交的改动只读保护；大规模修改前创建可回滚的本地提交（如不适合提交则备份）。
- **持续往下，不需要用户签收审查报告。**

## Phase 1：故事框架与 UI 互斥（约15%）

- 单一权威 StoryDirector、事件 ID、flags、触发器、排队、选项、时间段与存档。
- 统一对话展示与危险事件 Modal；玩家移动/手机/电脑/回家锁定与恢复。
- 开场街道+老周修车+群聊事件可以穿插验证。
- 通过：打开新档跑到群聊，保存重进不重复，选项记录正确。

## Phase 2：手机与电脑叙事系统（约20%）

- 手机界面（聊天、订单、地图、新闻、来电），与电脑端共用 chat/thread/message/news IDs。
- 电脑版新闻窗口与右下角弹窗，支持关闭、历史阅读、已读同步。
- 手机订单使用现有配送系统而不是第二份逻辑；手机来电能与门外场景演出联动。
- 通过：群聊和私信同端共享/同步；新闻解锁、消息通知、读档无重复消息；订单正常完成。

## Phase 3：四个可复用场景与三种轻演出（约25%）

- **出租屋**：生活物件、电脑、存储、冰箱、门、猫眼入口、雨声与灯光。
- **老城区街**：地面纹理、人行道、商家门头、驿站、小巷、装饰、NPC、可步行路线。
- **幸福花园外部**：花园/树/椅/花坛/门卫/公告栏/外卖架/3栋/停车棚/垃圾点，真实探索意义。
- **便利店室内**：货架、饮水冰柜、柜台、陈姨、灭火器、血迹/破损状态。
- 轻演出：普通居民楼楼道交付、14楼门前、电梯男人、深夜猫眼（可共享模板）。
- 通过：四大场景可从有效入口进出，交互点可点击并保存状态，非剧情建筑不会呈现为可进入却空无一物的陷阱。

## Phase 4：完整第一章剧情与分支（约20%）

- 逐节点录入本包故事台词、群聊、订单、短信、新闻、敲门事件；补上人物立绘/音效占位与过渡。
- 解决1404探索是可选、电梯事件必达、便利店和深夜敲门必达的触发关系。
- 便利店陈姨生死、老周五种结局、玩家是否在群里公开消息，均写入 flags 且在首章结尾有不同反馈。
- 从开场到新闻停单/章结束可连续游玩。
- 通过：至少“救陈姨+不开放门”和“不救陈姨+开放门”两条路径可完整走通。

## Phase 5：生存功能接入（约10%）

- 负重、装备/耐久、HP/体力、事件资源结算、普通感染者碰撞遭遇+逃跑概率、无感染。
- 普通探索免费一键直接回家；危险事件期间严格禁用；结算后正常恢复。
- 初期物资流、简易维修/储物与提示。**不用建设完整第2章基地生产。**
- 通过：逃跑成功与失败、武器足够/不足、背包超重、反复碰撞、在不同状态回家均符合规格。

## Phase 6：集成、验证与交付（约5%）

- 实际运行 Godot 可用的 headless 项目扫描/场景解析、单元/集成检查、数据 ID/资源引用与条件环路检测。
- 利用调试跳转复核电梯→便利店同一男人，深夜猫眼首次不露脸，老周无钥匙，重要消息能在手机电脑阅读。
- 回归原有移动/配送/电脑/旧档；修复可稳定复现的 P0。
- 生成 `docs/CH01_TEST_REPORT.md`, `docs/CH01_IMPLEMENTATION_STATUS.md`, `docs/DEVELOPMENT_LOG.md`, `docs/ART_ASSET_TODO.md`。
- 批量工作结束**一次性汇报**；不要求用户每阶段打开游戏验收。

## P0 验收硬门槛

- 第一章新档可从头到尾完成；章节标记准确。
- 没有会使玩家永久卡住的必需道具、漏掉1404、提前回家或不出电梯的状态。
- 危险事件不可回家；普通探索一键回家永久免费、无暗中结算。
- 没有实时追逐/攻击系统；普通地图感染者只有碰撞后结算，且不产生感染暴露。
- 便利店电梯男人身份匹配、店主可存活也可死亡；老周身份晚揭晓、无钥匙。
- 手机和电脑可收消息/新闻，关键剧情消息正确，保存加载不重复。
- 现有配送/移动没有被改坏；四个核心场景有内容，而非纯灰空地图。

## P1 最佳努力（不应牺牲 P0）

- 对话节奏可跳、短镜头/音效/天气、猫眼氛围、便利店动态环境。
- 感染者地图行为更生活化；持久状态细节更多；更多可选文本与公告栏。
- 视觉 polish：像素风整体统一、角色前后遮挡、低成本动态灯光、UI 细节。

## 结束报告建议格式

| 类别 | 完成 | 未完成或限制 | 验证方式 |
|---|---|---|---|
| 剧情 0–结尾 | 是/否 | ... | 端到端测试 |
| 手机聊天+订单 | 是/否 | ... | 互操作/存档 |
| 电脑新闻通知 | 是/否 | ... | 测试截图/手工 |
| 四张高复用图 | 是/否 | ... | 地图访问与热点检查 |
| 轻演出 | 是/否 | ... | 场景跳转 |
| 普通遭遇 | 是/否 | ... | 条件+资源结算 |
| 立即回家 | 是/否 | ... | UI 状态检查 |
| 剧情分支 | 是/否 | ... | flag 与结局覆盖 |

覆盖度说明：报告以 P0 项目数/实测可用数估计功能覆盖比例，**不能仅凭新增文件数量自称完成90%**。
