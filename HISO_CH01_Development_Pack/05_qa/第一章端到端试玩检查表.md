# 第一章集中试玩与自动测试矩阵

完成本章后统一试玩，无需每个小改动都验收。Codex 在持续开发中应尽可能自动执行以下检查并记录。

## A. 主线（新档）

- [ ] 首次开场可完成订单、老周修车剧情，老周无钥匙设定。
- [ ] 回出租屋可打开已有复古桌面，群聊按次序出现1404照片与台词。
- [ ] 手机可以查看同一组消息，阅读状态与电脑同步。
- [ ] 第二天可接普通订单与1203主线订单；普通楼宇不用完整爬楼地图。
- [ ] 幸福花园外部有可探索花园、外卖架、公告栏、门卫、可交互3栋与便利店。
- [ ] 可以选择不调查1404，照样遇到电梯男人。
- [ ] 选择调查1404时，看到双层纸条，林晓门后对话正确，电梯仍正常接续。
- [ ] 电梯男人袖口血迹、公文包等特征与后续便利店男人一致。
- [ ] 便利店袭击事件触发，无法直接回家；无武器仍可选择逃离/徒手/灭火器。
- [ ] 救/不救陈姨均能后续正常回家、推进消息和新闻。
- [ ] 老周失联消息、小鱼私信、老周“锁门”提醒按顺序到达。
- [ ] 敲门第一轮仅见雨衣人剪影，**不直接显示老周身份**。
- [ ] 来电显示老周+门外同步声音之后才揭晓身份。
- [ ] 深夜敲门事件内不可一键回家，选项都有可解释后果。
- [ ] 第一章结尾新闻、配送停单、资源提示和 `chapter_complete` flag 正确。

## B. 回家和交互互斥

- [ ] 普通街道、幸福花园、便利店普通购物时点击回家都**零资源/生命/时间消耗**并立刻到家。
- [ ] 普通感染者碰撞后回家不可用，结算后立即可用。
- [ ] 便利店袭击和老周危险剧情期间回家不可用，菜单快捷键不能绕过。
- [ ] 手机上打开聊天时不能同时 WASD 行走，关闭后移动正常。
- [ ] 电脑与普通对话/危险事件不会重叠弹窗或让 UI 无法关闭。
- [ ] 任何剧情关闭/读档不导致永久冻结移动。

## C. 遭遇与生存

- [ ] 感染者未接触玩家不会触发遭遇，也不追着玩家跑。
- [ ] 接触后选项出现一次，结算后分离并短暂无重复弹窗。
- [ ] 逃跑选项显示真实概率，成功无伤/失败扣资源且脱离。
- [ ] 普通逃跑失败**不会感染**，强行挣脱也不会感染。
- [ ] 武器耐久按选项正确扣除，低耐久状态不能透支。
- [ ] 负重正确汇总，超重无法捡取，负重影响逃跑概率。
- [ ] 老周直接开门特殊剧情有风险二次确认，可产生“暴露”，但不直接 Game Over。

## D. 分支与存档

- [ ] 未看1404线索不会阻塞便利店。
- [ ] 开场不多接单不会阻塞修车/主线。
- [ ] 有武器救陈姨 / 灭火器救陈姨 / 徒手 / 离开皆可结算。
- [ ] 老周 A–E 五种选项分别保存不同 flags。
- [ ] 公开/隐瞒老周去向能保存玩家选择。
- [ ] 读档后聊天消息不会重复、新闻不会重复推送、武器耐久不会二次扣除。
- [ ] 在便利店或敲门事件中途存档/退出时，载入能合理恢复到未结算决策，不可绕过。
- [ ] 从“剧情调试面板”跳转电梯/便利店/敲门时不会因缺前置 flags 空白或黑屏。
- [ ] 原有玩家移动、订单完成与电脑版桌面可继续正常运行。

## E. 视觉演出（人工试玩）

- [ ] 地图不再是大片纯灰色空地；街区有明显不同建筑/招牌/小道具/光照。
- [ ] 幸福花园具有可辨识花园、小路、公告栏、外卖架、3栋与便利店门头。
- [ ] 便利店具有收银台、货架、冷柜、灭火器，袭击后状态变化。
- [ ] 猫眼视角阴暗但可读，关键揭晓时能看清老周。
- [ ] 手机布局合理，无横向文字溢出；聊天支持滚动和已读。
- [ ] 电脑新增新闻弹窗不挡住所有原桌面功能。
- [ ] 关键音效缺失时也有字幕/视觉提示，不出现无声无字无法理解的关键事件。

## F. 最终阻断问题评级

**P0** 无法通关、崩溃、剧情重复/倒序、事件跳过、消耗双扣、无法打开手机/电脑/存档、地图完全空壳。

**P1** 部分次要分支缺 UI 反馈、临时素材不够精细、少量新闻延迟、轻微动画穿帮。

**P2** 第二章生产系统、六城区、完整居民楼、丰富动作动画、高级 NPC 生态。

提交时列出每个失败检查的复现步骤、预期结果、实际结果、涉及文件、优先级；不要只写“已测试”。
